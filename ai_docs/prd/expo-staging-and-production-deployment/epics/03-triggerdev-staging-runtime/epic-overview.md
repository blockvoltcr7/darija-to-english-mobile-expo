# Epic 03: Trigger.dev Development Runtime

## Objective

Verify the async translation worker through Trigger.dev's included Development environment, without paying for additional Trigger.dev staging or preview environments.

## Scope

- Confirm the Development environment path and secret requirements.
- Run the worker locally with `trigger.dev dev`.
- Trigger a real development-runtime job through the reachable API path.
- Capture Trigger evidence and operations notes for the local development worker.

## Out Of Scope

- Rewriting the worker.
- Changing provider orchestration.
- Paid Trigger.dev additional environments such as Staging or Preview.
- Production Trigger cutover beyond documented future commands.
