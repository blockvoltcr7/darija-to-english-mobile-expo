# Epic 02: EAS Environments And Config Safety

## Objective

Ensure preview, staging, and production builds receive the correct public mobile config while preventing local defaults and server secrets from leaking into app binaries.

## Scope

- Configure EAS public environment values.
- Audit public/private secret boundaries.
- Update `.env.example` and agent-facing docs.
- Add diagnostics or guards so device builds do not silently use `localhost`.

## Out Of Scope

- Provider secret rotation.
- Replacing Clerk or Supabase.
- Production API deployment itself.

## Verification

- EAS env values include only mobile-safe public variables.
- `EXPO_PUBLIC_API_BASE_URL` is HTTPS for preview/staging/production.
- Server-only keys are absent from Expo public env.
- App diagnostics make the active API URL visible enough for QA.
