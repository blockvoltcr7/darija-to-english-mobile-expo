Dedicated Agent Work Plan

Eight focused Codex lanes for building and verifying the assignment without mixing responsibilities.

8agent lanes
QAseparate verification lane
MCPpost-deploy verifier

Schema Agent

Owns validators, indexes, business IDs, and cents fields.

Seed Agent

Owns fake data, record counts, relationship proof, and 2/2/2/2 distribution.

Scoring Agent

Owns pure qualification rules, edge cases, reasons, and risk factors.

HTTP API Agent

Owns Convex HTTP Actions, route behavior, and JSON errors.

OpenAI Tool Agent

Owns getLoanQualification and Agents SDK proof.

Optional UI Agent

Owns evaluator console only, without backend logic.

Security QA Agent

Owns secrets, exposure, browser boundary, and final command proof.

MCP Verifier Agent

Owns table/function/log inspection after deployment.

Parallelization Rule

Split agents by write ownership: schema, seed data, scoring, API, agent service, UI, and QA. Keep scoring as a shared contract so API and agent work do not fork the business rules.
