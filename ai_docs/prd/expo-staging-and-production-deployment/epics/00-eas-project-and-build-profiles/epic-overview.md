# Epic 00: EAS Project And Build Profiles

## Objective

Create the EAS control plane for Darija to English so the app has explicit development, preview, staging, and production build lanes.

## Scope

- Initialize or document the EAS project association.
- Create `eas.json`.
- Preserve current native identifiers from `app.json`.
- Validate EAS config without deploying backend infrastructure.

## Out Of Scope

- API hosting.
- Trigger.dev deployment.
- TestFlight or Google Play submission.
- Production release.

## Verification

- `eas.json` exists.
- `npx eas-cli@latest build:configure` or equivalent project initialization is documented.
- Build profiles include `development`, `preview`, `staging`, and `production`.
- Native identifiers remain aligned with `app.json`.
