# Epic 03: API Response And Playback

## Objective

Expose TTS artifact metadata in authenticated translation detail responses and serve generated audio bytes only to the owning Clerk user.

## Scope

- Add `tts` metadata to `GET /v1/translations/:id`.
- Add authenticated `GET /v1/translations/:id/artifacts/english-audio`.
- Verify missing, failed, and cross-user artifacts return safe errors.

## Out Of Scope

- Mobile playback UI.
- Public or signed object URLs.
- Regenerating TTS on playback.

## Verification

- Translation detail returns `tts: null`, `tts.status: "succeeded"`, or `tts.status: "failed"` as appropriate.
- Playback route requires Clerk auth and returns 404 for missing or non-owned artifacts.
- Audio bytes are returned with safe content headers and no private object key leakage.
