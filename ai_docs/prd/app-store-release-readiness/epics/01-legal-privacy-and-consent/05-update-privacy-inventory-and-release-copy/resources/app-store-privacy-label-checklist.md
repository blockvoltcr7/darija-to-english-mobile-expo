# App Store Privacy Label Checklist

Map final implementation to App Store Connect answers.

- [ ] Contact Info: Email Address is marked collected, linked to user, not tracking.
- [ ] User ID is marked collected, linked to user, not tracking.
- [ ] Audio Data is marked collected, linked to user, not tracking.
- [ ] User Content / Other User Content covers transcripts, translations, and filenames.
- [ ] Diagnostics covers trace IDs, job IDs, Trigger run IDs, provider status, and safe errors where retained.
- [ ] Usage Data covers history, job counts, timestamps, quota/abuse controls, and provider run metadata where retained.
- [ ] Device ID / Identifiers are decided from final dependency privacy manifests and App Store upload warnings.
- [ ] Sensitive Info is reviewed because user audio/transcripts can contain sensitive content even when the app does not request it.
- [ ] Tracking remains "No" unless future code shares data for advertising, advertising measurement, or with data brokers.
- [ ] Privacy Policy URL and optional privacy choices/deletion URL match the public URLs from Epic 01.
- [ ] Open questions are promoted to Epic 05 blockers before App Store Connect privacy answers are filled.
