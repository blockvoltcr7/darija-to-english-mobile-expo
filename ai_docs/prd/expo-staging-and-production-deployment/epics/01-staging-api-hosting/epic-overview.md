# Epic 01: Staging API Hosting

## Objective

Deploy the existing `server/index.mjs` Express API to a reachable HTTPS staging host without moving paid provider calls into the mobile app.

## Scope

- Choose a Node-compatible API host.
- Add host-specific deployment configuration.
- Configure staging API secrets on the host.
- Verify `GET /health` over HTTPS.
- Document logs, rollback, and redeploy steps.

## Out Of Scope

- Refactoring to Expo Router API routes.
- Production API cutover.
- Usage quotas and billing.
- Changing translation pipeline behavior.

## Verification

- `https://<staging-api>/health` returns the expected health shape.
- Staging API logs are accessible.
- Deployment and rollback commands are documented.
- Server secrets remain only on the API host.
