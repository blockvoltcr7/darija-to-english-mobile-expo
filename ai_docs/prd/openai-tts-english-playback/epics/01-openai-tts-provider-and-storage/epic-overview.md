# Epic 01: OpenAI TTS Provider And Storage

## Objective

Add server-only OpenAI TTS generation and private Supabase Storage support for generated English audio artifacts.

## Scope

- Add server env contract for TTS feature flag and provider configuration.
- Add OpenAI speech generation helper.
- Add provider router and idempotency hash helper.
- Add generated artifact MIME mapping, object key builder, and upload helper.

## Out Of Scope

- Running TTS in the translation pipeline.
- API response and playback route.
- Mobile playback UI.

## Enriched Overview

### Scope

This epic adds the server-only generation and private storage building blocks for English TTS audio, with feature-flagged rollout, deterministic idempotency input, and storage metadata that later pipeline/API work can trust.

### Task Summary

| # | Slug | Type | Summary | Key Dependencies |
|---|---|---|---|---|
| 01 | `add-server-tts-env-contract` | Infrastructure | Extend `server/env.mjs` with disabled-by-default TTS config, OpenAI model/voice defaults, format validation, and public-secret guard awareness. | Epic 00 schema; PRD env spec; root public-env rules. |
| 02 | `add-openai-tts-provider` | Code | Add `server/tts/openai-tts.mjs` using the existing OpenAI SDK pattern to return audio `Buffer` plus safe provider metadata. | Task 01; existing OpenAI client usage in `server/translation-pipeline.mjs`. |
| 03 | `add-tts-provider-router-and-idempotency` | Code | Add `server/tts/index.mjs` for feature checks, output format metadata, provider routing, and deterministic hash generation. | Task 02; PRD idempotency rule. |
| 04 | `add-translation-artifact-storage-helpers` | Code | Extend `server/storage.mjs` with generated artifact object keys, MIME mapping, private upload helper, and safe storage metadata returns. | Task 03; `SUPABASE_TRANSLATION_ARTIFACTS_BUCKET`; existing original-audio storage pattern. |

### Execution Notes

- Shared files likely touched: `server/env.mjs`, `server/tts/*`, `server/storage.mjs`, and possibly `.env.example`.
- The mobile app must not receive OpenAI config, Supabase storage keys, object keys, or generated bytes during this epic.
- `ENABLE_TTS=false` remains the default behavior until pipeline QA explicitly enables the feature.
