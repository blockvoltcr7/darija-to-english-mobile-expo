# Epic 00: Artifact Schema And Repository

## Objective

Create the durable data model and repository layer for generated English TTS audio artifacts before any provider call or playback route is added.

## Scope

- Add `translation_artifacts` with constraints, indexes, RLS, and service-role-only grants.
- Add artifact repository helpers in `server/artifacts.mjs`.
- Extend provider-run operation contracts if the implementation records OpenAI TTS as a provider run.

## Out Of Scope

- OpenAI TTS generation.
- Supabase Storage upload/download helpers.
- Trigger.dev pipeline integration.
- Mobile playback UI.

## Enriched Overview

### Scope

This epic creates the durable server-owned artifact layer that makes generated English audio safe to store, retry, and serve later. It aligns with the PRD goal of treating TTS as an artifact lifecycle rather than a field on the text translation result.

### Task Summary

| # | Slug | Type | Summary | Key Dependencies |
|---|---|---|---|---|
| 01 | `create-translation-artifacts-migration` | RLS | Add `public.translation_artifacts` with Clerk ownership, artifact lifecycle fields, idempotency index, RLS, service-role grants, and updated-at trigger reuse. | Existing `translation_jobs`; `06-technical-specifications.md`; current Supabase migration conventions. |
| 02 | `add-artifact-repository-helpers` | Code | Add `server/artifacts.mjs` helpers for successful lookup, running/succeeded/failed transitions, and owner-owned audio artifact fetches. | Task 01; `server/translations.mjs`; Supabase admin client. |
| 03 | `extend-provider-run-operation-contract` | Code | Decide and implement the smallest provider-run diagnostics contract for `openai_tts` while keeping artifact rows as lifecycle source of truth. | Task 02; `provider_runs` SQL constraint; `PROVIDER_OPERATIONS`. |

### Execution Notes

- Shared files likely touched: `supabase/migrations/*`, `server/artifacts.mjs`, `server/translations.mjs`, and possibly provider-run SQL constraints.
- Keep table access server-mediated. Do not add direct `anon` or `authenticated` policies for generated audio metadata.
- The artifact table is prerequisite infrastructure for all provider, pipeline, API, mobile, and QA work.
